Website security scanner

The same scanner built for Pearce Studios, included in full: a graded A–F report covering 8 security-header checks (HSTS, CSP, clickjacking, MIME-sniffing, XSS, Referrer-Policy, Permissions-Policy, and cookie/session flags — the external-scan side of CSRF hardening), server information disclosure, TLS certificate details, platform & technology fingerprinting (CMS, frameworks, hosting, analytics), sitemap.xml & robots.txt, and email security — SPF, DMARC (with policy), DKIM across 14 common selectors, and MX. No DataForSEO key needed for this one, and it's SSRF-guarded: private/internal addresses are refused.

ℹ️ An external scan can only see what a site shows the public internet. It can't test login-protected areas, real CSRF tokens inside forms, or server-side code — use it as a fast outside-in checkup, not a penetration test.

Local SEO Toolkit — free and open source. Built on the DataForSEO APIs (SERP, Labs, Keywords Data, On-Page, Backlinks, Business Data, Reviews, Content Analysis, Domain Analytics, AI Optimization). Your API key pays DataForSEO directly — this tool charges nothing and stores nothing.

Maps grid method: one Live request per grid point, depth 100 with a depth-20 retry, matched by place ID → coordinates → name. See docs/API-MAP.md in the repo for every endpoint used.
